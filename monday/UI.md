# שכבת התצוגה — סדר עמודות, תצוגות, כרטיס פריט ולוחות בקרה

מקור האמת בקוד: `ui.mjs`. שם רשומים סדר העמודות, 24 התצוגות, 7 לוחות הבקרה ו-3 לשוניות הווידג'טים, כולל המזהים החיים.
הבדיקה `make/test/ui.test.mjs` מוודאת:
- שכל עמודה מופיעה בסדר פעם אחת בדיוק.
- שכל תצוגה נבנתה.
- שאף לוח בקרה לא חורג ממגבלות Pro.

## 2. כלל סדר העמודות (כל הלוחות)

**מזהה ← מצב ← מי ← מתי ← כמה ← הקשר ← פרטים ← נגזרות ← טכני (מוסתר)**

- **מזהה:** השם, ובלוחות תלויי-פרויקט גם הפרויקט.
- **מצב:** סטטוס או שלב, כלומר "מה צריך ממני".
- **מי:** אחראי או ספק.
- **מתי:** יעד או תוקף.
- **כמה:** סכום.
- **הקשר:** קישורים ללוחות אחרים.
- **פרטים:** טלפון, מיקום, קבצים.
- **נגזרות:** נוסחאות, דרגים ומראות.
- **טכני:** מזהה, יומן יצירה, מפתח וסטטוס אינטגרציה. מוסתרים בכל התצוגות.

העיקרון: מה שמחליטים לפיו נמצא בעמודות הראשונות, ומה שהמערכת ממלאת נמצא בסוף.

## 3. כרטיס פריט (Item Card) — הגדרה ידנית, פעם אחת לכל לוח

1. מבצעים קודם את הגרירה בסעיף 2, כי הכרטיס יורש ממנה את הסדר.
2. פותחים פריט כלשהו. ליד "עדכונים" לוחצים **+** ובוחרים **Item Card** (כרטיס פריט).
3. בהגדרות הכרטיס מסמנים את כל העמודות **חוץ מ**: מזהה, יומן יצירה, מפתח אינטגרציה וסטטוס אינטגרציה.
4. מומלץ להוסיף גם בלוח לידים, כי שמונה דירוגי Go/No-Go נוחים למילוי מתוך הכרטיס.

הגדרת הכרטיס חלה על כל הפריטים בלוח.

## 4. תצוגות שאין להן API (מתוך §5 באפיון)

| לוח | תצוגה | איך |
|---|---|---|
| לידים | קנבן לפי שלב | ‏+ ← Kanban ← עמודה: שלב עסקה. כרטיס: אחראי, ערך משוקלל, תאריך הגשת הצעה. |
| תיק פרויקטים | מפה לפי כתובת | ‏+ ← Map ← עמודה: כתובת. |
| משימות | כרטיסים לפי סטטוס | ‏+ ← Cards, או Kanban לפי סטטוס. |

כבר נבנו ב-API:
- **גאנט** בתיק פרויקטים, לפי ציר זמן, צבוע לפי שלב.
- **לוח שנה** במשימות, לפי יעד ומעקב.
- **צפי משוקלל** בלידים: תרשים ומונה.

| שיעור זכייה | סוללה "חוזה נחתם" (קירוב). למדד מדויק: מסנן ידני לשלבים סגורים בלבד. |
| ממצאים פתוחים, סיורים, ליקויים לפי קבלן | לוח ביצוע. ליקויים לפי קבלן: מסנן ידני או תצוגה "פתוחים" מקובצת לפי קבלן. A17 יוצר משימה כשחסר סיור. |
| הזמנות ממתינות, אספקות באיחור, דירוג | לוח רכש ותצוגה "אספקות באיחור". |
| סולם גבייה, ימי איחור, ימי גבייה | לוח גבייה. |

### מסננים ידניים מומלצים על ווידג'טים (אין API)

בכל ווידג'ט: ⋯ ← Filter.

- **מנכ״ל ← "משימות לפי אחראי וסטטוס":** סטטוס ≠ הושלם, בוטל.
- **מנכ״ל ← "סולם גבייה":** סטטוס חיוב ≠ שולם.
- **רכש ← "הזמנות ממתינות — שווי":** מסלול אישור = ממתין מנהל פרויקט, ממתין סמנכ״ל, ממתין מנכ״ל.
- **מנהלי פרויקטים:** כל מנהל פרויקט מסנן את הלוח לפי "אני" (Person filter), וכך נוצר "מנהל פרויקט אישי" בלי לשכפל לוחות.

## 6. הגבלת עמודות כספיות (§13)

בדיקת החובה מתקופת הניסיון עדיין פתוחה: האם הרשאות עמודה זמינות ב-Pro.
עד שתיבדק, העמודות הכספיות בתיק הפרויקטים גלויות לכל מי שרואה את הלוח. התצוגה "כספי — מנכ״ל" מסדרת אותן, אבל אינה מסתירה אותן מאחרים.
